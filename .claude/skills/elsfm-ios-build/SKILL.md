```bash

  -destination "platform=iOS Simulator,name=iPhone 16" build
```

## Critical Architecture Rules

### API Response Envelope (CRITICAL)
ALL ELSFM backend responses wrap data in a `{"data": ...}` key:
```json
{"data": {"id": 1, ...}, "message": "OK"}
{"data": [...], "pagination": {"total": 100, "current_page": 1}}
```

ApiClient already handles this via `DataResponse<T>` wrapper — do NOT try to decode `T` directly.

### Key Patterns
```swift
// ApiResult — 4 cases
enum ApiResult<T> {
    case success(T)
    case validationError([String: [String]])
    case unauthorized
    case networkError(Error)
}

// ViewModel — @Observable, not ObservableObject
@Observable @MainActor final class FooViewModel {
    private(set) var state = FooState()
}

// Inject via Environment
@Environment(SessionManager.self) var session
@Environment(PlaybackService.self) var playback
@Environment(\.apiClient) var apiClient
```

### Auth Endpoints
- Login: `POST /api/v1/auth/login` → returns `{data: {token, user}}`
- Register: `POST /api/v1/auth/register`
- Send OTP: `POST /api/v1/auth/send-otp` with `{email}`
- Verify OTP: `POST /api/v1/auth/verify-otp` with `{email, otp}`
- Logout: `POST /api/v1/auth/logout`

### Home / Discovery
Home uses `GET /api/v1/channel` (NOT /discovery). Returns `[Channel]` array.
Each Channel has: id, name, image, description, tracks: [Track]?

### Play Logging
Every track play must fire `POST /api/v1/tracks/{id}/plays`.
PlaybackService calls this automatically when a new track starts.
